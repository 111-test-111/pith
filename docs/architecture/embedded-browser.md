# 内嵌浏览器（右栏 Browser 面板 + `browser_*` 工具）

> 2026-09-17 自 pi-web worktree `native-subagents`（webview 统一架构）移植；参考实现的权威文档是 pi-web `docs/architecture/embedded-browser.md`，本文件是 pi-app 命名/宿主下的改写。**以代码为准**——发现失配先改代码或同步本文；AGENTS.md 只保留不变量与指针。实测铁律见下方陷阱表；设计基线与决策记录见 `docs/superpowers/specs/2026-09-17-embedded-browser-design.md`（§11 为铁律的 canonical 版本）。

- **架构总览**：pi-app 恒为 Electron 桌面形态，无 pi-web 的 web 模式分支。主进程持唯一 `BrowserService` 单例（[src/main/browser/service.ts](../../src/main/browser/service.ts)，`initBrowserService`/`getBrowserService`，无 pi-web 的 `globalThis` 热重载守卫——main 无 HMR），经 playwright-core `chromium.connectOverCDP("http://127.0.0.1:<port>")` 连**壳自身**的调试端口，guest target 以 Page 形态浮现于 `contexts()[0]`。human 与 agent 页同为 renderer 托管的原生 `<webview src=markerUrl partition="persist:pith-browser">`（输入/IME/剪贴板/滚动全原生），**同一 guest 双驱动**：agent 工具与人看/操作同一个 webview，agent 工作时人可直接接管；人在 guest 上的原生输入经主进程 `input-event` 中继 `bumpInteraction`（进程内直调，无 pi-web 的 HTTP `POST /api/browser/interact`；按 contents 300ms 节流），递增 interaction generation 使旧 snapshot ref 失效（`StaleSnapshotError` 引导重新 snapshot）。登录态共享持久化 partition——这正是首次使用一次性 consent（`browserConsent`，写 `app-settings.json`）的告知点。

- **调试端口常开**（[cdp-port.ts](../../src/main/browser/cdp-port.ts)）：`appendCdpSwitches(pickCdpPort())` 在模块顶部、app ready 前——`appendSwitch` 之后无效，开关式启用会要求重启应用，且建页握手依赖确定性连接。端口随机 19000–38999、仅 127.0.0.1，`PITH_CDP_PORT`（1–65535 整数）可覆盖（检查脚本固定端口即用它；`check-browser-ui.mjs` 另有 `PITH_CHECK_CDP_PORT` 逃生口）；必须同时挂 `remote-allow-origins=http://127.0.0.1`，否则 playwright CDP WebSocket 的 Origin 头被拒。`getCdpPort()` 是 service 初始化取端口的唯一途径（与 Chromium 实际生效一致）。残余风险接受：本机任意进程理论上可连此端口驱动 app（本地攻击者本已等价于用户）。

- **建页握手（控制反转）**：Electron 的 CDP 不实现 `Target.createTarget`（陷阱 1）。`createPage` 入队 `pendingCreates`（`getStatus` 暴露给渲染端）并挂起等待（15s 超时 `BrowserHostUnavailableError`）；Workspace 订阅 `browser:state`，见 agent owner 的 pendingCreate 且 browser 面板未开即 `openSidePanelTab('browser')`（事件驱动，取代 pi-web 的 2.5s 轮询兜底；human 的 pendingCreate 不自动开面板）；`BrowserPageView` 把 pendingCreate 物化为 marker webview，`dom-ready` 后经 `browser:seen` 握手（上报 wcId；**建页首跳导航交服务端 `goto`**——renderer 自导航会输掉与 reconcile 的 marker 竞态）；reconcile（1s `unref` 轮询 `context.pages()`）按 marker 登记 runtime 后 waiter 放行。`registerExternalPage`（`browser:seen`）兼作 state-only 兜底：CDP 连接前已存在的 guest 不进 `context.pages()`（陷阱 7，Electron 43 起实测），先按上报登记，target 随后浮现时 reconcile 升级为完整登记。

- **关页由 renderer 驱动**：webview guest 的 `page.close()` 永久挂死（陷阱 2）。`closePage` 只摘注册表（`closingTargetIds` 给两个轮询周期的宽限，防 reconcile 按 marker 重登），renderer 下一轮 `browser:state` 发现页面消失即卸载 `<webview>`（guest 随之销毁），reconcile 的消失清扫兜底。最后一页关闭 → `onBrowserEmpty` → Workspace `closeSidePanelTab('browser')` 自关面板标签。

- **三态可见性铁律（陷阱 3）**：选中页正常渲染；**未选 agent 页 `opacity: 0` + `pointer-events: none` 全尺寸托管，绝不可 `display: none`**——display:none 的 guest click 超时、screenshot 永不返回、`fill` 静默无效（实测），opacity 形态下 timer/rAF 满速、click/pressSequentially/screenshot 全部可用；未选 human 页维持 `display: none`（无服务端驱动，省资源）。判据在 [BrowserPageView.tsx](../../src/renderer/src/components/app/BrowserPageView.tsx) 的 IRON RULE 块。webview 的显式像素定尺寸（ResizeObserver）也是三态的配套：`display:none → visible` 的过渡中 guest 实测尺寸滞后，布局必须由 host 驱动。

- **agent 页归属与回收**：owner = `HUMAN_OWNER`（`"human"`）或 `agentOwner(sessionId)`（`agent:<SDK session id>`，fork 不变）。弹窗（guest `window.open`/target=_blank）经 per-contents `setWindowOpenHandler` deny 后以 `browser:popup` 事件收口转发，owner 按 opener 的 webContentsId 继承（agent 页的弹出归 agent，`wcIdMapRef` 映射；marker URL 一律 deny 只记日志；壳窗口 http(s) deny + `shell.openExternal`）。会话 dispose（`disposeManaged`）与删除（`deleteSession`）→ `closePagesForOwner(agentOwner(id))`；运行中止**不**关页（跨 turn 保留，与 pi-web 一致）。

- **IPC / 事件面**（HTTP 路由 → 类型化 IPC，DTO 进 `shared/types.ts`，[ipc.ts](../../src/main/ipc.ts) 注册、[preload](../../src/preload/index.ts) 逐一暴露）：`browser:status`（顺带踢一次 reconcile）、`browser:consent`、`browser:createPage`、`browser:closePage`、`browser:seen`、`browser:elementAt`（服务端 `resolveElementAt` 路径；UI 批注优先 renderer 侧 `executeJavaScript`）、`browser:theme`（失败静默——纯外观）、`browser:clearData`。事件经 `win.webContents.send`，**一律无 `eventSequence`**（`context_usage` 规则——给它们序列号会破坏 renderer 的快照/事件对账）：`browser:state`（完整状态快照；注册表任何变更——reconcile、agent 动作、建/关页、consent、crash——后推送，`notifyState` ~30ms 合并；renderer store 整体替换、浅比较无变化不通知）、`browser:popup`、`browser:download`、`browser:guest-shortcut`。

- **面板（Ruling H keep-alive）**：[BrowserPane.tsx](../../src/renderer/src/components/app/BrowserPane.tsx) 挂在右栏 `SidebarPanel` 的 keep-alive 层——**切换 rail 标签只是隐藏层，关闭浏览器标签才卸载 webview、销毁 guest**（`SidebarPanel.tsx` 的 keep-alive 注释；页面/滚动/播放状态跨切换保留）。`BrowserStore` 由 Workspace 持有（比面板活得长：rail 折叠会卸载面板但快照仍在，重开即画）。guest 聚焦时浏览器 chrome 的按键经 `before-input-event` 拦下（preventDefault 挡 guest 原生行为）以 `browser:guest-shortcut` 广播渲染层，由 BrowserPane 分流：⌘±/0 → zoom 阶梯、⌘F → 查找条、⌘P → `webview.print()`（Ruling M；仅本面板 rail 标签激活时接管；此通道**无可编辑目标守卫**——按键来自 guest 即面板实际激活，页面内输入框聚焦时浏览器按键仍优先，与 Chromium 一致）。面板自身快捷键（window 捕获 + stopPropagation）同理只在激活标签生效，但让位可编辑目标。

- **工具条与页面功能**（[BrowserPageView.tsx](../../src/renderer/src/components/app/BrowserPageView.tsx) / [BrowserOverlays.tsx](../../src/renderer/src/components/app/BrowserOverlays.tsx)）：back/forward/reload（**reload = 服务端 `reloadGuest` = `goto(currentUrl)`，绝不发 CDP `Page.reload`**——陷阱 6，它会杀死 guest 或打到壳窗口）· URL `Input`（回车经 `normalizeNavigationUrl`：裸域名补 https、裸 host:port 补 http）· 缩放簇 −/100%/+（`BROWSER_ZOOM_STEPS` 25%–300% Chromium 阶梯、平局吸附低档；全局档 localStorage `pi-app:browser-zoom`；`effectiveWebviewZoom(pageZoom, uiScale)` 保住纯函数——pi-app 无 UI 缩放，`uiScale` 恒 1）· **每次 `dom-ready` 都必须重应用缩放**（与握手闩锁分离——首次 marker → 真实网站及跨 origin 导航都可能重置 guest zoom）。查找条：`webview.findInPage/stopFindInPage` + `found-in-page`（`finalUpdate` 后的 ordinal/matches 才是终值），去抖 200ms、Enter/Shift+Enter、Esc 输入框让位。历史面板 ≤500 条（`pi-app:browser-history`，连续同 URL 去重、title/favicon 由页面事件回填、favicon 回落站点根）。起始页 = about:blank 覆盖层 + 最近打开（`pi-app:browser-recents` ≤8，仅 human **did-navigate 真实文档导航**记录，SPA in-page 不记）；每次打开面板自动开一个 about:blank（一次性闩锁等首个 status）。恢复快照 `pi-app:browser-open-pages` ≤12：**建页时预写目标 URL**（did-navigate 前页面条/快照就有真实 URL，慢加载页关面板不丢快照），重开面板无页且 consent 已过才逐页恢复，实时来客（pages 非空）优先。设备模拟：预设（iPhone SE/15 Pro、Pixel 8、Galaxy S23、iPad Air）+ 自定义宽高（草稿输入、失焦夹取 200–3840）；**元素级视口**——把 webview 元素钉预设宽高居中呈机身框，**不走 CDP `setDeviceMetrics`**（会破坏「guest 视口 == 元素」不变量）；批注坐标全以 webview 元素 rect 为原点。清除浏览数据：两步确认 → `session.fromPartition(BROWSER_PARTITION).clearStorageData(...)+clearCache()+clearAuthCache()`。下载：`will-download` 自动存 `~/Downloads`（重名去重），完成/失败发 `browser:download`，工具条 transient 指示钮 → `shell.showItemInFolder`（pi-web 是完成对话框打断，pi-app 改指示）。亮暗自适应：`browser:theme` → `setColorScheme` 对全部 runtime 页发 CDP `Emulation.setEmulatedMedia`（prefers-color-scheme），**页面注册时重放**（新页/重连恢复的 guest 也跟随）。

- **聊天外链 → 内置浏览器**（[markdown.tsx](../../src/renderer/src/lib/markdown.tsx) 锚点渲染器 + [open-link.ts](../../src/renderer/src/lib/browser/open-link.ts)）：偏好 `pi-app:open-links-in-browser`（默认开，Settings → Browser 可关）开时，明文左键 http(s) 链接 → `requestBrowserOpenLink(href)` 入队 + 派发 `BROWSER_OPEN_LINK_EVENT`（`pith:browser-open-link`）→ Workspace 开/激活面板 → BrowserPane drain 队列，按 popup 同款 marker 流程建 human 页并导航。修饰键点击、非白名单 scheme 走原生行为不变。

- **批注模式**（[BrowserAnnotate.tsx](../../src/renderer/src/components/app/BrowserAnnotate.tsx)）：capture 层拦掉 guest 全部指针事件且**批注模式全程常驻**（选中目标后也不撤，否则 guest 重新收到 hover/点击，页面元素被真实互动）；选中期间点击框内 = 取消、框外 = 改选。元素解析走 **renderer 侧 `webview.executeJavaScript`** 的 elementFromPoint 片段（与服务端 `resolveElementAt` 同源；trailing 节流 ~80ms + 序号守卫防乱序；点击与最近悬浮 <3px 直接复用）——服务端 runtime 在 renderer 侧导航后会滞留旧文档，webview 执行通道始终绑活文档。**滚轮必须显式转发**：`webview.sendInputEvent({type:"mouseWheel", x, y, deltaX, deltaY})`，只发纯像素 delta 且**符号与 DOM WheelEvent 相反（取反）**，**转发前按主轴清零副轴**（|dy|≥|dx| 判纵向；macOS 触控板几乎总带副轴噪声，不清零两轴都消费甚至整事件被吞）——带 `wheelTicks*`/`hasPreciseScrollingDeltas` 的 payload 在 guest 上被静默吞掉。滚动期间抑制悬浮高亮，停稳（最后事件后 250ms，macOS 惯性顺延）后在落点解析一次。Esc 退出（仅激活标签；文本输入让位）。提交 → `pith:browser-annotation` CustomEvent → Workspace → Composer 草稿插入。

- **agent 工具（13 个，`BROWSER_TOOL_NAMES`）**：`browser_navigate / browser_pages / browser_focus / browser_snapshot / browser_click / browser_hover / browser_select / browser_type / browser_press_key / browser_scroll / browser_wait_for / browser_screenshot / browser_close`。纯逻辑在 [tools-core.ts](../../src/main/browser/tools-core.ts)（ref 解析、`capSnapshotText` 20k 默认 / 200k 硬顶、`wrapUntrustedContent` 不可信边界、`diffSnapshotLines`），工具定义在 [tools.ts](../../src/main/browser/tools.ts)（`createBrowserTools({ ownerId, service })`，描述/错误文本英文，`UNTRUSTED_NOTE` + `<<<untrusted-web-content>>>` 边界原样保留）。执行语义（全部 service 层，实测纪律）：文本输入走键盘事件链 `click → ControlOrMeta+A → pressSequentially`（**禁 `fill()`**——陷阱 4）；`agentScroll` 先 CDP mouseWheel（视口中心）再校验 scrollY，被吞时 `window.scrollBy` 兜底（陷阱 5）；snapshot = `ariaSnapshot({ mode: 'ai' })`、ref allow-list 全量重建、`selector` 子树 / `diff` 行级差异；**动作后快照先 settle**：120ms 预热 → URL 变化或 evaluate 失败判导航中 → 等 domcontentloaded；否则 MutationObserver 120ms 采样连续两次静默才快照，持续繁忙页面按 1.5s 预算截断（计时经 `BrowserServiceDeps.settle` 可注入，单测归零）；`browser_wait_for` 条件超时不吞，未满足条件列在不可信边界外（timeout 0.5–30s）；screenshot = JPEG q60、显式 5s 超时 + 8s 重试一次（陷阱 8），annotate 标签在页内离屏 canvas 合成（≤50 个，不进 DOM、失败静默回退原图）；全部交互/导航 8s/20s 超时，绝不容 playwright 默认 30s 挂死。错误映射各有明确文本（`ConsentRequiredError` 引导用户去面板确认——模型不得代确认；`BrowserHostUnavailableError` 引导重试/开面板；Stale/InvalidRef/PageGone/PageNotFound/NavigationBlocked 同）。元素解析用页内 `elementFromPoint`（陷阱 9）。

- **工具注册门控（四处同步清单）**：13 个名字必须同时出现在——① 激活集（[manager.ts](../../src/main/pi/manager.ts) `initializeSession`/`applyActiveTools`，`browserToolsFlag ? APP_BROWSER_TOOL_NAMES : []`）；② `catalog.ts` 的 `APP_TOOL_NAMES`（builtin 分类）；③ [tool-icons.tsx](../../src/renderer/src/lib/tool-icons.tsx)（每工具一枚映射）；④ [tool-categories.ts](../../src/renderer/src/lib/tool-categories.ts) 的 `browser` 类别。**注册本身 service 门控，永不做 flag 门控**：`buildSession` 的 `customTools` 在 `getBrowserService()` 存在时注册（子会话路径同样注册——子代理 profile 可按名授权，frozen ceiling 按名放行），因为 customTools 数组在 build 时冻结、SDK 每次注册表重建复用它，而 `setActiveToolsByName` 静默丢弃未知名字——flag 门控注册会让 Settings 的开关对既有会话永远无效。**开关即时生效**走 `setAppendPrompt` 模式：`setBrowserAgentTools` → 空闲会话立即 `reload()`，流式会话等 `agent_settled` 补；SDK reload 会重新激活全部已注册工具，所以 `reloadManagedSession` 在 reload 完成后**重应用激活集**——这一步才是关掉开关时移除 browser_* 名字的机制。首次使用还需 consent，`ConsentRequiredError` 由 `browserToolErrorText` 转成引导文本。

- **刻意不移植**（相对 pi-web）：`lib/browser-notifications.ts`（Web 通知，属会话通知域）；web 模式占位分支与 `BrowserUnavailableError` 的 web 语义；Next.js HTTP 路由层与 `BROWSER_SERVICE_VERSION` 热重载守卫（main 无 HMR，单例由 ipc.ts/shutdown.ts 拥有）；pi-web 的全局 UI 缩放接入（`uiScale` 恒 1，`effectiveWebviewZoom` 保留为纯函数）。**改进项**：`browser:state` 推送取代 2.5s 轮询；`setPermissionRequestHandler` 权限白名单（pi-web 完全没有——默认放行；pi-app 默认拒全部敏感权限，仅放行 `fullscreen`/`clipboard-sanitized-write`/`pointerLock`，[wiring.ts](../../src/main/browser/wiring.ts) `decideBrowserPermission`）；input 中继零 HTTP（进程内直调）；beUI 原生 UI + en/zh-CN 双语；工具目录/图标/类别/子代理 ceiling 生态集成；Electron 44 铁律重证固化为回归断言；下载入工具条指示。

- **退出与断线**：`shutdown.ts` cleanup 追加 service `dispose()`——**只丢引用，绝不调 `Browser.close()`/`context.close()`**（connectOverCDP 的 close 发 CDP `Browser.close`，会退出整个 app；陷阱 12）。CDP WS 随进程退出关闭。`disconnected` 断线：runtime/注册表全清，下次 `ensureStarted` 重连（壳重启自愈路径）。service 单例懒建（首次 `browser:*` 或工具执行），CDP 连接 single-flight，reconcile timer `unref`。

**webview / 批注附加陷阱**（同表地位，无编号）：

- `allowpopups` 必须以**字符串属性**展开写在 `<webview>` 上（React 剥布尔属性，裸 `allowpopups` 无效）。
- 批注滚轮转发：纯像素 delta + 符号取反 + 主轴判定清零副轴；`wheelTicks*`/`hasPreciseScrollingDeltas` 载荷被 guest 静默吞掉（垂直/水平/小数像素均 1:1 生效的只有纯像素形态）。
- 缩放**每次 `dom-ready` 重应用**，不能与只执行一次的 marker 登记/首跳握手共用闩锁（跨 origin 导航会重置 guest zoom；批注框与页面分属两个坐标系就是它的症状）。
- 设备模拟绝不走 CDP `setDeviceMetrics`：guest 视口必须等于 webview 元素，批注坐标系（元素 rect 原点 + `guestOffset()`）才有单一路径。
